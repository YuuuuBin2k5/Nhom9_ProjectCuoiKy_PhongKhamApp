# Thư mục `prod` — tài liệu dự án PhongKham

Đây là nơi ghi **cấu trúc**, **kiến trúc** và **logic hiện tại** của workspace (backend + mobile), được đối chiếu trực tiếp với mã nguồn.

| Tài liệu | Nội dung |
|----------|----------|
| [KIEN_TRUC_VA_LOGIC.md](./KIEN_TRUC_VA_LOGIC.md) | Kiến trúc tổng thể, cây package, mô hình dữ liệu, API đang có, app Android, phần chưa triển khai |
| [PLAN_AUTH_UI_VA_VAI_TRO.md](./PLAN_AUTH_UI_VA_VAI_TRO.md) | **Kế hoạch** UI Toothly, auth OTP + JWT, vai trò; cây thư mục file theo package |
| [PLAN_CHECKIN_VA_PHAC_DO.md](./PLAN_CHECKIN_VA_PHAC_DO.md) | **Kế hoạch** Self Check-in QR, Lập phác đồ điều trị; Phases A–E |
| [PLAN_SMART_DENTAL_BO_SUNG.md](./PLAN_SMART_DENTAL_BO_SUNG.md) | **Bổ sung** Hàng đợi nâng cao (X-Quang, đôn ưu tiên), QR động, Real-time, UI chuyên sâu (Odontogram, Form theo dịch vụ) |
| [PLAN_UI_UX_VA_DESIGN_SYSTEM.md](./PLAN_UI_UX_VA_DESIGN_SYSTEM.md) | **UI/UX & Design System:** palette (Trust Blue / Teal), form kính mờ, typography; spec Patient / Bác sĩ / Lễ tân / Kiosk; component kit & JSON form |

**Cập nhật:** khi thêm controller/service/entity hoặc đổi luồng nghiệp vụ, nên chỉnh file trên để `prod` luôn phản ánh đúng repo.
